04 / 12
傾きで「像」はどうズレる?
Image-plane offset under tilt
PEDESTAL TILT
観察
台座が 傾いている と、
太陽は 像の中央に来ない。
中央から たて にずれる量を Δh (デルタ・エイチ)
中央から よこ にずれる量を Δa·cos(h)
このズレは 写真を見れば測れる。
実は、ズレは 太陽の方向 と 台座の傾き で きれいに決まる。
Δh = θ · cos(a − φ)
a = 太陽の方位、φ = 傾きの方位、θ = 傾きの大きさ
Δh と Δa·cos(h) を 写真から 測る

05 / 12
ズレは sin と cos で書ける
The key formula
PEDESTAL TILT
公式
太陽の方位 a と 傾きの方位 φ。
この 「ずれ角」 a − φ を使うと、
像のズレは とてもキレイに 書ける。
Δh   =   θ · cos(a − φ)
Δa·cos(h) = θ · sin(a − φ) · sin(h)
中学の sin / cos で扱える式。
でも未知数が θ と φ の 2 つ あるので、
このままだと解きにくい…
a − φ = 「太陽の方向 と 傾きの方向 の角度差」
parabolic-antenna
06 / 12
テクニック: 2 つの数 p と q に分ける
Linearization with p, q
PEDESTAL TILT
トリック
θ と φ を 直接 求めず、
こういう 2 つの数 を求める。
p  =  θ · cos(φ)
q  =  θ · sin(φ)
cos の加法定理 を使うと、ズレの式が p, q の 1 次式(掛け算が直線的な式)になる:
Δh = p · cos(a) + q · sin(a)
→ これなら 連立方程式 で解ける!
「斜めの矢印 (θ, φ)」 を 「たて (q) と よこ (p)」 に分解

07 / 12
3 回の観測を 連立方程式 にする
3 equations, 2 unknowns
PEDESTAL TILT
実測したズレ Δh を 3 回ぶん 集めると、こうなる:
9 時
−0.5°  =  p · cos(90°) + q · sin(90°)   →  −0.5 = q
12 時
−0.5°  =  p · cos(180°) + q · sin(180°)   →  −0.5 = −p
15 時
+0.5°  =  p · cos(270°) + q · sin(270°)   →  +0.5 = −q
解
p = +0.5   ,   q = −0.5
式が 3 本あって 未知数は 2 つ。
少し多いので、最小二乗法 で
「いちばん辻褄が合う p, q」を選ぶ。
!
「観測が 3 回 = 式が 3 本」
「未知数は 2 つ」 なので、
ぴったり 1 つ の答えに 絞り込める。
parabolic-antenna
08 / 12
p, q を θ と φ に戻す
Pythagorean theorem + atan2
PEDESTAL TILT
最後の一手
p, q が出れば、θ と φ は
中学数学で すぐに 戻せる。
θ = √( p² + q² )   ← 三平方の定理
φ = arctan( q / p )   ← 角度に戻す (atan2)
直角三角形の 斜辺 が θ、
傾いた角度 が φ。
※ コードでは math.hypot(p,q) と math.atan2(q,p) を使う。
底辺 p、高さ q、斜辺 θ、底角 φ の 直角三角形
